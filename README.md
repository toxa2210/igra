# 🪐 Космический Кликер

Вирусная игра-кликер в космическом стиле. Кликай по планете, добывай звёзды, покупай апгрейды и покоряй галактику!

## 🎮 Как играть

1. Открой `index.html` в браузере (или запусти через GitHub Pages).
2. Кликай по планете 🪐 — каждый клик приносит звёзды ⭐.
3. Покупай улучшения в магазине:
   - **Сила клика** — больше звёзд за каждый клик
   - **Автодобыча** — спутники, ракеты и станции приносят звёзды сами
4. Открывай достижения и ставь рекорды!

## ✨ Возможности

- 🖱 Клики с анимацией всплывающих наград
- 🛒 7 уровней улучшений с растущей ценой
- 🏆 8 достижений
- 💾 Автосохранение прогресса (localStorage)
- 📱 Адаптивный дизайн — играй с телефона

## 🛠 Технологии

Чистый HTML + CSS + JavaScript, без зависимостей и сборки.

## 📁 Структура

```
├── index.html   — разметка игры
├── style.css    — космический дизайн
└── game.js      — игровая логика
```

## 🚀 Запуск

Просто открой `index.html` в любом современном браузере — ничего устанавливать не нужно.
